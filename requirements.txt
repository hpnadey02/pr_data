# --- DO NOT INSTALL pyarrow ---
# On Windows, pyarrow (which pandas imports whenever it is present) loads native DLLs that
# shadow the ones onnxruntime needs. A later `import onnxruntime` then either raises
#   "DLL load failed while importing onnxruntime_pybind11_state"
# or, non-deterministically, hard-crashes the interpreter with
#   "Windows fatal exception: access violation"
# which no try/except can contain. onnxruntime is pulled in by chromadb, so installing
# pyarrow silently disables semantic retrieval and can kill the uvicorn worker mid-request.
#
# Import-ordering was tried as a fix and rejected: it only holds if the backend package is
# imported before pandas, which nothing can guarantee across tests, scripts and plugins.
#
# The only thing that wanted pyarrow was Streamlit's st.dataframe, so the data preview in
# frontend/streamlit_app.py renders as HTML instead (see _render_table). DuckDB provides
# Parquet natively. tests/test_import_order.py fails the build if pyarrow reappears.
